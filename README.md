# fe-practice

## 作品の概要

基本情報技術者試験の学習を目的として、Javaを使用して基本的なアルゴリズムやデータ処理を実装している学習用リポジトリです。

1日1テーマを目安に、配列操作、探索、文字列処理、ソートなどの問題を実際にコードを書きながら学習しています。

各学習内容は `day01`、`day02` のようにフォルダを分けて管理しています。

## 作品の目的・背景

基本情報技術者試験では、プログラムの処理内容を読み取り、変数や配列の値がどのように変化するかを理解する力が必要になります。

問題を解くだけではなく、自分でJavaのコードを書いて実行することで、アルゴリズムの動きをより深く理解することを目的として作成しました。

また、継続的にコードを書くことで、Javaの基本文法やプログラミングの基礎を定着させることも目的としています。

## 使用した言語・技術

## 主な学習内容

以下のような処理をJavaで実装しています。

- 配列の最大値・最小値の探索
- 合計値・平均値の計算
- 条件に一致する要素のカウント
- 線形探索
- 配列の添字探索
- 配列の逆順処理
- 文字列の探索
- 文字の出現回数のカウント
- 回文判定
- 大文字・小文字・数字の判定
- 配列要素の入れ替え
- バブルソート

今後も基本情報技術者試験の学習に合わせて追加していく予定です。

## 工夫したポイント

単純にコードを写すだけではなく、処理の流れを確認しながら実際にコンパイル・実行することを意識しています。

また、1つのテーマを1つのフォルダに分けることで、過去に学習した内容を後から確認しやすい構成にしています。

```text
fe-practice
├── day01_max_value
├── day02_min_value
├── day03_sum
├── day04_average
├── ...
└── day25_bubble_pass
```

前に学習した内容を次の問題でも利用し、少しずつ複数の処理を組み合わせることで、段階的にアルゴリズムへの理解を深めています。

## 苦労したポイント

配列の添字やループの開始位置・終了条件など、処理を1つずつ追わないと間違えやすい部分に苦労しました。

特に、

```java
numbers.length - 1
```

や、

```java
numbers[i + 1]
```

など、配列の範囲を意識する必要がある処理については、実際の値の変化を確認しながら理解を進めました。

また、Git・GitHubについても、リポジトリの管理単位やブランチ、commit、pushなどを実際に使用しながら学習しています。

## 起動方法・使用方法

### 1. リポジトリをクローン

```bash
git clone git@github.com:MitoYuuki/fe-practice.git
```

### 2. 実行したいフォルダへ移動

例：

```bash
cd fe-practice/day25_bubble_pass
```

### 3. コンパイル

```bash
javac -encoding UTF-8 Main.java
```

### 4. 実行

```bash
java Main
```
